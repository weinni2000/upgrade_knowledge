# base_geoengine_demo: 17.0 -> 18.0

| Title | Explanation | Odoo Commit Hash |
| --- | --- | --- |
| `<tree>` view tag renamed to `<list>` | Odoo 18.0 renames the tree view type to list view everywhere: the `<tree>` root tag in view `arch` becomes `<list>`, and `view_mode`/`views` entries using `"tree"` become `"list"` (e.g. `view_mode="tree,form"` -> `view_mode="list,form"`). Odoo ships a dedicated `upgrade_code` script for this rename (`odoo/upgrade_code/17.5-01-tree-to-list.py`, versioned `17.5` so it applies to any 17.0->18.0 migration): run it via `odev upgrade-code -V 18.0 <db> --from 17.0 --to 18.0 --glob "<module>/**/*"` — note the glob MUST end in `/**/*` (not just `/**`), since a bare `**` only matches directories under `pathlib.Path.glob`, not files, and the script silently rewrites nothing. No `attrs`/`states` usage was present in this module, so no separate attribute-syntax migration was needed here. | script: `odoo/upgrade_code/17.5-01-tree-to-list.py` in Odoo core (no single migration commit; shipped as a first-party `upgrade_code` rewrite script) |
